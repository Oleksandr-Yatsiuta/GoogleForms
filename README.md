1.1 To run app use `pnpm dev`from root(google-form-lite).

1.2 To run just client use `cd/client` from root(google-form-lite) and use `pnpm dev`.

1.3 To run just server use `cd/server` from root(google-form-lite) and use `pnpm dev`.

1.4 To upload all files (if `pnpm dev` doesn't work ) use `pnpm install` from root(google-form-lite).


2.1 To run tests use `pnpm test` from root(google-form-lite).

2.2 To run client tests use `pnpm test:client`.

2.3 To run server tests use `pnpm test:server`.

2.4 Watch mode `pnpm test:watch`.
